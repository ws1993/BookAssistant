# 评价结构化 pros-cons 改进说明

## 更新概述

对 `evaluate_book` 工具进行重大升级，新增结构化的 **pros-cons 表达式**，让图书评价更有条理、更实用，帮助用户快速决策。

**对标目标**：Goodreads/豆瓣读书的高质量评论提炼（80%成熟度）

---

## 核心改进

### 1. 新增 pros-cons 表达式类型

全新的结构化表达式，专门用于展示图书的优缺点分析：

```typescript
{
  type: "pros-cons",
  title?: string,                    // 默认"优缺点分析"
  intro?: string,                    // 引言
  overallVerdict?: string,           // 总体评价
  pros: Array<{                      // 优点（必填，至少1条）
    title: string,                   // 优点标题
    body?: string                    // 详细说明
  }>,
  cons?: Array<{                     // 不足（可选）
    title: string,                   // 不足标题
    body?: string                    // 详细说明
  }>,
  readerFit?: {                      // 读者适配度（可选）
    bestFor?: string[],              // 适合哪些人
    notFor?: string[]                // 不适合哪些人
  }
}
```

---

### 2. 增强评价查询

更新 `evaluate_book` 的 smart-search 查询，明确要求结构化信息：

**更新前**：
```
《书名》这本书的评价怎么样？请汇总公开评分、优点、不足与适合/不适合的读者。
参考豆瓣读书、Goodreads 等公开评分与书评。
```

**更新后**：
```
《书名》这本书的评价怎么样？请结构化汇总以下信息：
1. 整体评分（豆瓣、Goodreads等公开平台）和评分分布趋势
2. 主要优点（3-5条，每条用简短标题+详细说明）
3. 主要不足或缺点（2-4条，同样用标题+说明）
4. 适合的读者类型（bestFor：哪些人会喜欢这本书）
5. 不适合的读者类型（notFor：哪些人可能不喜欢）
6. 阅读节奏和难度（slow/medium/fast，easy/moderate/challenging）
7. 情感基调（轻松、沉重、治愈、压抑等）

请参考豆瓣读书、Goodreads、微信读书等公开评分与高质量书评，提取实际读者的真实反馈。
```

## 视觉设计

### 优点展示（绿色系）
- ✓ 图标 + 标题 + 详细说明
- 浅绿色背景 + 绿色边框
- 清晰的层次结构

### 不足展示（红色系）
- ✗ 图标 + 标题 + 详细说明
- 浅红色背景 + 红色边框
- 与优点形成对比

### 读者适配度
- 独立面板展示
- ✓ 适合 / ✗ 不适合
- 帮助用户快速判断匹配度

## 使用建议

### 对话中的关键词识别

当用户说：
- "这本书**值得读吗**" → 使用 pros-cons + readerFit
- "优点和缺点是什么" → 重点填充 pros/cons
- "**我适合读这本书吗**" → 重点填充 readerFit
- "**推荐理由**是什么" → 重点填充 pros

### 最佳实践

1. **优点 3-5 条**：太少不够全面，太多失去重点
2. **不足 2-4 条**：诚实但不苛刻
3. **标题简洁**：5-10字，一眼看到核心
4. **详细说明可选**：如果标题够清楚，body 可以省略
5. **读者适配度必填**：这是用户最关心的

### pros/cons 提取技巧

从评论中提取优缺点时：
1. **寻找高频词**："硬核"、"烧脑"、"节奏慢"、"人物单薄"
2. **关注极端评价**：五星和一星评论最能体现优缺点
3. **提炼共性**：多条评论提到的才是真正的优/缺点
4. **保持客观**：用"部分读者反映"而非"这本书就是"
