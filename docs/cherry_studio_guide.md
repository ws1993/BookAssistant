# BookAssistant 在 Cherry Studio 中的使用指南

## 🚀 快速开始

BookAssistant 有 8 个工具，涵盖图书推荐、对比、总结、评价等全流程。以下是最实用的提示词示例。

---

## 📚 工具 1：通用推荐（recommend_books）

### 基础用法

```
推荐3本科幻小说
```

```
给我推荐适合初学者的心理学书籍
```

### 进阶用法（利用个性化参数）

```
推荐5本商业书籍，要求：
- 节奏：快节奏
- 难度：轻松入门
- 心情：励志向上
- 避开：学术性太强的书
```

```
推荐科幻小说，但要避开暴力和恐怖内容，适合青少年阅读
```

### 详细参数示例

```
推荐悬疑推理小说，要求：
- 数量：5本
- 心情：烧脑、紧张刺激
- 节奏：medium（中等）
- 难度：moderate（中等）
- 长度偏好：medium（中篇）
- 避开敏感内容：性描写、暴力血腥
- 必须满足：完结、中文
```

---

## 🔍 工具 2：相似推荐（recommend_similar_books）

### 基础用法

```
推荐和《三体》类似的书
```

```
我喜欢《活着》，推荐5本风格相似的书
```

### 指定相似维度

```
推荐和《三体》主题相似的书（关注科幻主题，不是写作风格）
```

```
推荐和《小王子》情感基调相似的书，避开同一作者
```

### 参数说明
- `similarityFocus`: auto / theme / style / mood / genre
- `count`: 1-10本
- `avoidAuthor`: true/false（是否避开同一作者）

---

## ⚖️ 工具 3：多书对比（compare_books）

### 基础用法

```
对比《三体》和《基地》这两本书
```

```
帮我对比《活着》《平凡的世界》《白鹿原》这三本书，哪本更适合入门？
```

### 指定对比维度

```
对比《原则》《思考快与慢》《穷查理宝典》，重点对比：
- 实用性
- 阅读难度
- 适合人群
```

### 使用场景
- "这几本书选哪个？"
- "哪本更适合初学者？"
- "哪本更烧脑？"

---

## 📋 工具 4：书单生成（generate_booklist）

### 基础用法

```
生成一份"科幻入门"书单，5本书
```

```
给我一份女性成长主题的书单，按难度从易到难排列
```

### 进阶用法

```
生成商业思维书单，要求：
- 数量：8本
- 目标读者：创业者
- 组织方式：从易到难
- 重点：实践应用
```

### 组织方式选项
- `beginner-to-advanced`: 从易到难
- `thematic`: 按主题分类
- `chronological`: 按时间顺序
- `auto`: 自动选择

---

## 📖 工具 5：图书总结（summarize_book）

### 基础用法

```
总结《三体》这本书
```

```
总结《置身事内》，重点说明经济政策部分
```

### 剧透控制

```
介绍《三体》，完全不要剧透（我还没读过）
```

```
总结《三体》，可以适度剧透，但不要透露结局
```

```
详细总结《三体》全部内容，包括结局（我已经读过了）
```

### 剧透级别
- `none`: 严格无剧透，仅背景设定
- `light`: 适度剧透到中段（默认）
- `full`: 完整剧透含结局

---

## ⭐ 工具 6：图书评价（evaluate_book）

### 基础用法

```
《三体》这本书评价怎么样？
```

```
评价《活着》，重点说说适合什么人读
```

### 会得到什么
- 整体评分和分布
- 主要优点（3-5条）
- 主要不足（2-4条）
- 适合的读者类型
- 不适合的读者类型
- 阅读节奏和难度
- 情感基调
- **内容警告**（如有）

---

## 💬 实用对话示例

### 场景 1：找书推荐

**你**：我想读点轻松治愈的书，最近压力有点大

**AI 会调用**：recommend_books
- query: "轻松治愈"
- mood: ["轻松", "治愈"]
- pace: "medium"

---

### 场景 2：选书决策

**你**：我在《人类简史》和《枪炮、病菌与钢铁》之间犹豫，哪本更适合历史小白？

**AI 会调用**：compare_books
- books: [《人类简史》, 《枪炮、病菌与钢铁》]
- focus: "哪本更适合历史小白"

---

### 场景 3：系统化学习

**你**：给我一份心理学入门书单，从浅到深，5本书

**AI 会调用**：generate_booklist
- theme: "心理学入门"
- count: 5
- progression: "beginner-to-advanced"

---

### 场景 4：了解图书

**你**：《三体》讲什么的？我还没读过，别剧透

**AI 会调用**：summarize_book
- title: "三体"
- spoilerLevel: "none"

---

### 场景 5：查看评价

**你**：《活着》这本书好不好？适合我这种轻阅读用户吗？

**AI 会调用**：evaluate_book
- title: "活着"

AI 会重点关注 "适合的读者类型" 来回答你的问题

## 🌟 特色功能

### 1. 内容警告保护
如果你对某些内容敏感（暴力、性、心理创伤等），可以明确说明：

```
推荐悬疑小说，但要避开暴力血腥和恐怖元素
```

AI 会在推荐时过滤这些内容。

---

### 2. 剧透分级
总结时可以精确控制剧透程度：

```
总结《三体》，我读到一半了，可以讲到中段，但别透露结局
```

---

### 3. 结构化评价
评价时会自动给出优缺点对比和读者适配度：

```
评价《人类简史》
```

你会得到：
- ✓ 优点：视角独特、通俗易懂、激发思考...
- ✗ 不足：部分观点有争议、深度有限...
- ✓ 适合：对历史感兴趣的通识读者
- ✗ 不适合：专业历史研究者

---

### 4. 系统化书单
书单生成会考虑难度递进、主题分类或时间顺序：

```
生成科幻入门书单，从易到难
```

你会得到：
1. 入门级：《小王子》
2. 进阶级：《三体》
3. 高级：《基地》
... 并附带阅读建议

## 💡 常见问题

**Q: 我不知道要什么书，怎么办？**  
A: 描述你的心情、场景或需求即可：
```
我最近很焦虑，想读点能让我平静下来的书
```

**Q: 推荐的书太多/太少？**  
A: 明确指定数量：
```
推荐5本科幻小说
```

**Q: 推荐的书不符合我的口味？**  
A: 提供更多限制条件：
```
推荐科幻，但不要太硬核，要轻松好读的
```

**Q: 想避开某些内容？**  
A: 明确说明：
```
推荐悬疑，但不要血腥暴力和心理阴暗的
```
