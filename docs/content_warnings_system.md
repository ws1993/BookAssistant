# 内容警告系统改进说明

## 更新概述

新增 **content-warnings 表达式**，为图书添加系统化的内容警告，保护敏感读者群体。

**对标目标**：StoryGraph 的核心竞争力（95%成熟度）

---

## 核心改进

### 新增 content-warnings 表达式类型

全新的结构化表达式，专门用于展示图书的内容警告：

```typescript
{
  type: "content-warnings",
  title?: string,                    // 默认"内容警告"
  intro?: string,                    // 引言
  overall?: string,                  // 总体提示
  warnings: Array<{                  // 警告列表（必填）
    category: string,                // 警告类别
    level?: "none" | "mild" | "moderate" | "graphic",  // 程度
    details?: string,                // 详细说明
    pageReferences?: string[]        // 涉及位置
  }>,
  safeFor?: string[],               // 可安全阅读的人群
  cautionFor?: string[]             // 需要谨慎的人群
}
```

---

## 四个警告级别

### 1. none - 无

**含义**：该类别内容不存在或极少

**视觉**：灰色标签

**示例**：暴力：无

---

### 2. mild - 轻微

**含义**：存在但程度较轻，偶尔出现

**视觉**：黄色标签

**示例**：暴力：轻微（打斗场景，无详细描写）

---

### 3. moderate - 中等

**含义**：明显存在，多次出现或有一定描写

**视觉**：橙色标签

**示例**：暴力：中等（多处战斗场景，有伤亡描写）

---

### 4. graphic - 严重

**含义**：大量存在，详细描写，可能令人不适

**视觉**：红色标签

**示例**：暴力：严重（详细的血腥场面和残忍画面）

## 使用示例

### 示例 1：《三体》内容警告

```json
{
  "type": "content-warnings",
  "title": "内容警告",
  "intro": "基于豆瓣、Goodreads等平台读者反馈汇总",
  "overall": "这本书涉及文革背景和科幻战争场景，包含一定的暴力和心理创伤内容，敏感读者请注意。",
  "warnings": [
    {
      "category": "暴力",
      "level": "moderate",
      "details": "包含文革期间的批斗场景、外星入侵战争描写，有一定的暴力元素但非重点。",
      "pageReferences": ["第一部前半段", "第三部"]
    },
    {
      "category": "心理创伤",
      "level": "moderate",
      "details": "涉及家庭悲剧、绝望情绪和对人类未来的悲观思考，可能引发情绪波动。"
    },
    {
      "category": "死亡场景",
      "level": "mild",
      "details": "包含人物死亡和文明毁灭的描写，但非血腥类型。"
    },
    {
      "category": "性描写",
      "level": "none",
      "details": "无性相关内容。"
    }
  ],
  "safeFor": [
    "成年读者",
    "青少年读者（16+）",
    "对科幻和宇宙哲学感兴趣的读者"
  ],
  "cautionFor": [
    "对文革历史敏感的读者",
    "容易产生存在主义焦虑的读者",
    "不适合心理较为脆弱或正在经历抑郁的读者"
  ]
}
```

**渲染效果**：
- ⚠️ 总体提示（黄色背景）
- 暴力 [中等] - 包含文革批斗...
- 心理创伤 [中等] - 涉及家庭悲剧...
- 死亡场景 [轻微] - 包含人物死亡...
- 性描写 [无] - 无性相关内容
- ✓ 可安全阅读：成年读者、青少年...
- ⚠️ 需要谨慎：对文革历史敏感...

## 视觉设计

### 总体提示
- 黄色背景 + 橙色边框
- ⚠️ 图标
- 醒目但不过分刺眼

### 警告卡片
- 根据级别显示不同颜色边框
  - 无：灰色
  - 轻微：黄色
  - 中等：橙色
  - 严重：红色
- 级别标签：彩色圆角徽章
- 涉及位置：灰色小字

### 适读提示
- 浅色背景面板
- ✓ 可安全阅读（绿色）
- ⚠️ 需要谨慎（橙色）

## 最佳实践

### 对话中的识别

当用户说：
- "这本书**有没有暴力**场景" → 提供 content-warnings
- "**适合小孩看吗**" → 重点关注 cautionFor
- "有**触发警告**吗" → 完整的 content-warnings 表达式
- "我对**血腥场面敏感**" → 在推荐时考虑 contentWarningsToAvoid

### 数据提取技巧

1. **寻找关键词**："trigger warning"、"content warning"、"敏感内容"、"不适合"
2. **分析评论**：低星评论常提及敏感内容
3. **参考分级**：电影分级、图书馆分级可作参考
4. **社区标签**：Goodreads shelves、豆瓣标签

### 呈现原则

1. **客观中立**：不带价值判断
2. **具体明确**：说清楚是什么类型的暴力/性内容
3. **程度准确**：根据实际情况标注级别
4. **保护优先**：宁可多标也不漏标
