### 第二轮改进（下午-晚上）

#### 6. 多书对比工具 ✅
- **新工具**：compare_books
- 支持2-5本书同时对比
- 自动或自定义对比维度
- 输出 decision-matrix 表达式

**实现内容**：
```typescript
{
  books: Array<{ title, author? }>,  // 2-5本
  compareAspects?: string[],         // 对比维度
  focus?: string                     // 对比重点
}
```

**价值**：
- 高频场景："《三体》和《基地》哪个更适合我？"
- 展示 decision-matrix 能力
- 帮助用户快速决策

---

#### 7. 内容警告与推荐集成 ✅
- 评价工具自动包含内容警告信息（第8点）
- 总结工具简要标注敏感内容
- 推荐工具明确过滤 contentWarningsToAvoid

**实现细节**：
1. **evaluate_book**：查询中新增第8点，要求提取内容警告
2. **summarize_book**：查询中补充"如有敏感内容请标注"
3. **recommend_books**：当用户指定 contentWarningsToAvoid 时，明确要求过滤

**价值**：
- 真正打通内容警告和推荐系统
- 保护敏感读者
- 内容警告能力：**60% → 75%**
